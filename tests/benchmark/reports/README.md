# Benchmark smoke reports

[Curated synthetic comparison](examples/synthetic-v1/index.html) · [Synthetic Markdown](examples/synthetic-v1/report.md) · [Four-fixture smoke summary](smoke-summary.json).

The curated example is a copy of an append-only synthetic run, with its original run ID and fingerprints preserved. It is infrastructure evidence, not real-chart accuracy. Real cell/grid/count references in this smoke dataset are unreviewed and their scores are **Not evaluated**. Source images are local relative references, not copied raw data.

Run `npm run benchmark:run -- --diagnostics cells` to generate the complete four-fixture visual comparison under `reports/runs/`. Follow the root benchmark README to serve that directory from localhost for relative images. Runtime runs stay local/ignored; no public website is deployed.
