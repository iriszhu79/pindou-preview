## Implemented independent recovery work

- Source-image crop rectangle: mouse/touch movement and four 44px corner targets.
- Fit image, 1–6× source zoom, inspect/pan mode, full-image scrolling and reset.
- Live row/column grid overlay in original image coordinates. Overlay and handles scale with the source, not a resized recognition raster.
- Keyboard crop adjustment (arrows / Shift+arrows); advanced numeric coordinates are optional collapsed controls.
- Automatic failures distinguish grid not detected, rejected/uncertain geometry, invalid manual geometry, and classification failure. Recovery offers **Adjust Grid Manually** and retains the rejected baseline geometry when one exists.
- Crop/dimension edits invalidate prior classification and confirmation until a fresh analysis completes, even if fields are changed back. Manual selection never confirms a project automatically.
- Existing cell classifier, palette corrections, export and reviewed Workspace import remain intact.

Zoom is controlled by a touch-friendly slider; inspect mode provides native scrolling. Custom two-finger image pinch is not implemented or claimed. Handle touch gestures prevent page scrolling; native device/Safari acceptance remains untested.

### Code-level failure paths (not an image-specific root-cause claim)

1. Projection rejects pixels outside luminance130–247 or with channel spread above28. Extremely pale lines can be excluded.
2. Peak extraction and line continuation use global maximum-relative floors, while candidate scores sum line strengths. Unequal major/fine-line weights can influence which period wins.
3. Each axis returns only one strongest contiguous chain; missing evidence breaks a chain immediately. No joint X/Y candidate ranking occurs.
4. Y evidence is sampled only in edge bands derived from the chosen X candidate. An incorrect X period/crop changes the Y search region.
5. Duck's reported message originates after both axes were chosen, when X/Y spacing ratio falls outside0.86–1.16. Exact chosen periods are unknown until the original is replayed.
6. Teapot's message comes from `detectAxis` when the best chain has fewer than7 or more than301 lines; which axis and competing evidence caused this is unknown without replay.
7. Numbered-axis text/borders and color-block periodicity are not independent candidate evidence channels in the baseline. Full coordinate/legend OCR is not implemented.

These are general architectural investigation targets, not a claim that a darkness threshold alone explains these images. The requested replacement multi-candidate ranking (fine/major lines, border/axis evidence, color-block periodicity), mixed-weight/compression/occlusion matrix, and exact three-real-image comparison remain pending the original fixture files.
